# VIA --- Índice de documentación

## Proyecto

**VIA** es una red social educativa donde estudiantes y docentes pueden
crear, descubrir y compartir imágenes generadas con inteligencia
artificial con fines educativos.

**Slogan:** Ideas que inspiran aprendizaje.

## Stack definido

-   Next.js
-   React
-   TypeScript
-   Tailwind CSS
-   Clerk --- autenticación
-   Supabase --- PostgreSQL + Storage + RLS
-   Vercel --- despliegue
