# VIA --- Alcance y MVP

## 1. Objetivo del MVP

Construir el núcleo funcional de VIA antes de incorporar gamificación
avanzada, recomendaciones sofisticadas o generación de imágenes mediante
IA.

## 2. MVP obligatorio

### Autenticación

-   Clerk.
-   Login.
-   Registro.
-   Logout.
-   Protección de rutas.

### Perfil

-   Avatar.
-   Nombre.
-   Username.
-   Biografía.
-   Publicaciones.

### Publicaciones

-   Crear.
-   Leer.
-   Editar.
-   Eliminar.
-   Subir imagen.
-   Título.
-   Descripción.
-   Categoría.

### Feed

-   Listado de publicaciones.
-   Orden básico.
-   Tarjeta de publicación.

### Interacción

-   Like.
-   Quitar like.
-   Comentario.
-   Eliminación de comentario propio.

### Comunidades

-   Listado.
-   Detalle.
-   Miembros.
-   Publicaciones de la comunidad.

### Búsqueda

-   Búsqueda básica.
-   Filtro por categoría.

### Roles

-   Usuario.
-   Moderador.
-   Administrador.

## 3. Segunda etapa

-   Compartir con métricas.
-   Seguir usuarios.
-   Ranking.
-   Medallas.
-   Reportes completos.
-   Panel administrativo.
-   Recomendaciones.

## 4. Tercera etapa

-   Generación de imágenes.
-   Recomendaciones avanzadas.
-   Sugerencias automáticas de etiquetas.
-   Moderación asistida por IA.
-   Funciones pedagógicas avanzadas.

## 5. Criterio de salida del MVP

No se incorporará una funcionalidad nueva al MVP si compromete la
estabilidad del núcleo: autenticación, publicaciones, almacenamiento,
feed, interacción, comunidades y permisos.
